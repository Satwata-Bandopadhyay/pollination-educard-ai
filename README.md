# Pollination EduCard AI 🌱

**Pollination EduCard AI** is an interactive learning platform that instantly generates structured study notes, dynamic educational diagrams, and multiple-choice quizzes using Pollinations AI. 

### ✨ Key Features:
* **Instant Study Notes:** Generates structured markdown notes tailored to different education levels.
* **Dynamic Diagrams:** Automatically creates relevant educational illustrations.
* **Interactive Quizzes:** Test your knowledge with AI-generated MCQs.
* **Contextual Q&A:** 'Ask AI' lets you clear your doubts instantly.
* **Export to PDF:** Download your notes and quizzes with a single click.

### 🔒 Security
This project uses a highly secure BYOP (Bring Your Own Pollen) authentication flow directly via Pollinations AI.
